# Incident Write-Ups

A collection of real security incidents I handled, written up and anonymized 
(no company names, usernames, or identifying details) to demonstrate hands-on 
detection and response experience.

## Contents

- [`aitm-detection.md`](./aitm-detection.md) — Detected and remediated an 
  Adversary-in-the-Middle (AITM) phishing attack by correlating EDR alerts 
  with sign-in logs.
- [`sentinelone-fp-triage.md`](./sentinelone-fp-triage.md) — Investigated a 
  SentinelOne EDR false-positive quarantine, verified via hash/VirusTotal, 
  and tuned detection to prevent recurrence.

## Why this repo exists

Real incident data can't leave the organizations I've worked for, so these 
are narrative case studies rather than logs or screenshots — focused on the 
investigative process, decisions made, and outcomes. For visual, hands-on 
proof of the same skills, see [`soc-home-lab`](../soc-home-lab).# incident-writeups
